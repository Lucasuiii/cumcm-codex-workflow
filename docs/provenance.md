# Provenance boundary

This repository is independently authored.

## Permitted inspiration

General software and workflow concepts may inform the design, including:

- staged execution;
- explicit checkpoints;
- resumable state;
- machine-readable artifact contracts;
- deterministic structural validators;
- separate computation, visualization, and writing stages.

## Excluded material

The repository must not contain:

- decrypted or encrypted Modex skill content;
- copied proprietary prompts, templates, scripts, or binaries;
- activation, licensing, device-binding, or key material;
- reverse-engineered proprietary implementation details not needed for interoperability;
- local audit dumps or extracted application resources.

If public upstream software is used later, record its repository URL, exact revision, license, files used, and modifications before merging it.
