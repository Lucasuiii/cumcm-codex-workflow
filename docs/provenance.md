# Project provenance

This repository is independently designed and authored for reproducible CUMCM work.

The project is built around versioned JSON contracts, stable cross-artifact IDs, exact result locators, local deterministic checks, version-bound paper review, append-only human decisions, and public-safe synthetic regressions.

When public upstream software is used, record its repository URL, exact revision, license, files used, and modifications before merging it.
