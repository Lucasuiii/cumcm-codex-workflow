# 独立复核请求

请在不读取原建模/调试对话的条件下，核对本包中的官方问题、模型、所选计算后端、正式运行和结果。先验证包内 digest 与 upstream freshness；不要用旧包复核新结果。

重点确认：

1. 模型是否回答了题目真正要求的问题；
2. 目标方向、上下界、单位、约束和物理含义是否一致；
3. 是否存在重复计量、遗漏变量、跨问矛盾或无依据外推；
4. 代码是否实现了文档声明的模型；
5. 结果是否来自保存的正式运行，并满足官方约束；
6. 哪些结论可进入论文，哪些属于 P0、P1 或 P2。

P0 仅用于真实错误、答非所问、关键 claim 无证据、代码/结果不一致或严重 provenance 问题；P1 是模型、假设、baseline、验证或敏感性方面的 concern；P2 是表达、图表或额外实验建议。只有开放 P0 可以给出 `revision_required`。

若本包是 targeted re-review，优先检查列出的既有 P0 是否解决。可以报告新 P1/P2，但不要把它们升级成阻断项；只有新发现且有明确证据的 P0 才能新增阻断。
